AI Receipt Scanning
Powers the "Auto-fill from Receipt" button employees see when adding an expense

Employees will see "Not configured — admin must add Gemini key in Settings → AI" on the scan button until a key is saved here.
Don't have a key? Get a free one at aistudio.google.com/apikey — sign in with a Google account, click "Create API key", and paste it above.

Payslip Email (Resend)
Powers the "Email Payslip" button on the Payroll page

Get a free key at resend.com (3,000 emails/month free) — the "from" address must be on a domain you've verified there.

Heads up: Resend's API is built to be called from a server, not directly from a browser like this app — most browsers will block the request even with a valid key. If sending fails, the app will offer to open your own email app instead with the payslip pre-filled, which always works. For fully automatic sending, a small server-side relay (e.g. a Supabase Edge Function) would be needed — ask if you'd like help setting that up.

Default PIN: 1234 — change this immediately.
